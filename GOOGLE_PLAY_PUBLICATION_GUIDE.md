## 1. Подготовка приложения

### 1.1. Настройка подписи приложения (обязательно!)

**ВАЖНО:** Google Play требует, чтобы приложение было подписано цифровой подписью.

#### Шаг 1: Создание ключа для подписи

**Windows:**
```bash
create_keystore.bat
```

**Linux/Mac:**
```bash
chmod +x create_keystore.sh
./create_keystore.sh
```

**Или вручную:**
```bash
cd mobile_app/android
keytool -genkey -v -keystore ~/upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

**Вам будет предложено ввести:**
- Пароль для хранилища ключей (запомните его!)
- Имя и фамилию
- Название организации: `Новая Жизнь` или ваше название
- Город, область, код страны (например: `Moscow`, `Moscow`, `RU`)

#### Шаг 2: Создание файла key.properties

Создайте файл `mobile_app/android/key.properties` на основе `mobile_app/android/key.properties.example`:

```properties
storePassword=ВАШ_ПАРОЛЬ_ХРАНИЛИЩА
keyPassword=ВАШ_ПАРОЛЬ_КЛЮЧА
keyAlias=upload
storeFile=ПУТЬ_К_ФАЙЛУ_КЛЮЧА
```

**Пример для Windows:**
```properties
storePassword=MySecurePassword123!
keyPassword=MySecurePassword123!
keyAlias=upload
storeFile=C:/Users/1/upload-keystore.jks
```

**Пример для Linux/Mac:**
```properties
storePassword=MySecurePassword123!
keyPassword=MySecurePassword123!
keyAlias=upload
storeFile=/home/username/upload-keystore.jks
```

**⚠️ ВАЖНО:** Файл `key.properties` уже добавлен в `.gitignore` и не будет закоммичен в git.

#### Шаг 3: Обновление build.gradle

✅ **УЖЕ ВЫПОЛНЕНО!** Файл `mobile_app/android/app/build.gradle` уже обновлен с поддержкой подписи.

### 1.2. Обновление AndroidManifest.xml

Обновите название приложения:

```xml
<application
    android:label="Новая Жизнь"
    android:name="${applicationName}"
    android:icon="@mipmap/ic_launcher"
    android:usesCleartextTraffic="true">
```

### 1.3. Обновление версии приложения

В `mobile_app/pubspec.yaml`:
```yaml
version: 1.0.0+1
```
- `1.0.0` - версия для пользователей (versionName)
- `1` - номер сборки (versionCode) - должен увеличиваться с каждой загрузкой

### 1.4. Сборка App Bundle (рекомендуется Google Play)

**Windows:**
```bash
build_release.bat
```

**Linux/Mac:**
```bash
chmod +x build_release.sh
./build_release.sh
```

**Или вручную:**
```bash
cd mobile_app
flutter build appbundle --release
```

Файл будет создан в: `mobile_app/build/app/outputs/bundle/release/app-release.aab`

**Альтернатива - APK:**
```bash
flutter build apk --release
```

Файл будет создан в: `mobile_app/build/app/outputs/flutter-apk/app-release.apk`

## 4. Создание приложения в Google Play Console

### 4.1. Создание нового приложения

1. Войдите в Google Play Console
2. Нажмите "Создать приложение" (Create app)
3. Заполните:
   - **Название приложения:** `Новая Жизнь`
   - **Язык по умолчанию:** Русский
   - **Тип приложения:** Приложение (App)
   - **Бесплатное или платное:** Бесплатное (Free)
4. Примите условия использования
5. Нажмите "Создать приложение"

### 4.2. Настройка контентного рейтинга

1. Перейдите в раздел "Контентный рейтинг" (Content rating)
2. Заполните анкету:
   - Категория: Социальные сети / Благотворительность
   - Возрастной рейтинг: Для всех возрастов
3. Получите рейтинг (обычно "Для всех")

## 📝 Дополнительные рекомендации

### Безопасность ключа подписи

**ВАЖНО:** Сохраните файл ключа (`upload-keystore.jks`) и пароль в безопасном месте!

- Без ключа вы не сможете обновлять приложение
- Рекомендуется хранить в нескольких местах (облако + локально)
- Не коммитьте `key.properties` в git (добавьте в `.gitignore`)

### Обновления приложения

При каждом обновлении:
1. Увеличьте `versionCode` в `pubspec.yaml` (например: `1.0.0+2`)
2. Соберите новый App Bundle: `flutter build appbundle --release`
3. Загрузите в Google Play Console
4. Заполните примечания к выпуску

### Тестирование перед публикацией

1. Создайте внутренний тест (Internal testing)
2. Добавьте тестовых пользователей
3. Проверьте работу приложения
4. После успешного тестирования отправьте в Production
